# 中西合璧 · 每日运势分析系统 — PRD V1.0

---

## 一、项目背景与市场分析

### 1.1 市场现状

| 维度 | 传统中国命理产品 | 西方星座产品 | 本项目定位 |
|------|----------------|-------------|-----------|
| 代表产品 | 中华万年历、测测、准了、灵机文化 | Co-Star、The Pattern、同道大叔 | — |
| 核心数据 | 八字、黄历、五行、紫微 | 星盘、行星相位、宫位 | 八字 + 星盘 + 黄历 三合一 |
| 分析方式 | 单一命理模块 | 单一星盘模块 | 跨体系融合解读 |
| 用户体验 | 各自为政，切换模块 | 各自为政，切换模块 | 统一入口，一键综合运势 |

**核心洞察**：市面上的产品，要么只做中国命理，要么只做西方星座。即使像"测测""准了"这种同时提供两者的产品，也是把它们作为独立模块——用户在"八字"tab 看一遍，再切到"星座"tab 看一遍，两条分析互不关联，没有交叉解读。

**市场空白**：缺少一款真正把中国传统命理与西方星座星盘深度融合的产品——用同一套算法引擎，在同一个结果页面，输出一份"中西合璧"的每日运势。

### 1.2 目标用户画像

| 用户类型 | 特征 | 需求 |
|---------|------|------|
| **都市白领 (核心)** | 25-40岁，对星座有认知，也信风水命理 | 每天早上看一眼运势，做决策参考 |
| **命理爱好者 (核心)** | 懂八字/星座基础知识，热衷自我探索 | 需要更专业、更深层的融合分析 |
| **年轻女性 (核心)** | 18-30岁，社交属性强 | 可分享的运势卡片，颜值高的页面 |
| **好奇尝鲜者** | 对传统文化+西方玄学都有兴趣 | 低门槛体验，不需要懂专业术语 |

## 二、产品目标

### 2.1 北极星指标

**"每日融合运势解读卡片"的日活跃用户数 (DAU)**

### 2.2 V1.0 核心目标

1. 用户输入出生年月日时和性别 → 系统自动排八字、排星盘、查黄历
2. 输出一份"中西合璧"的每日运势解读
3. 解读内容包括：综合运势评分、爱情、事业、财运、健康、幸运色/数字/方位
4. 界面在移动端优先，适配桌面端
5. 支持运势卡片分享（生成图片）

## 四、核心算法设计

### 4.1 八字排盘引擎

基于 `lunar-python` 库，已验证可直接使用：

- **输入**：公历出生年月日、时（需精确到小时）、性别
- **输出**：
  - 年柱、月柱、日柱、时柱（天干+地支）
  - 四柱五行、纳音
  - 十神（以日干为"我"推算各柱十神关系）
  - 藏干（地支藏干）
  - 日主五行
  - 生肖

### 4.2 黄历引擎

同样基于 `lunar-python`：

- **今日宜忌**：宜做什么、忌做什么
- **冲煞**：今日冲什么生肖
- **吉神方位**：喜神、福神、财神、贵神方位
- **彭祖百忌**
- **今日五行**：日柱五行属性
- **建除十二神**

### 4.3 星盘引擎

**方案 A（推荐）**：`pyswisseph` — 基于瑞士星历表 (Swiss Ephemeris)，精度最高，但需要编译安装。

**方案 B（备选）**：`flatlib` — 纯 Python，无编译依赖，精度稍低但够用。

**方案 C（轻量）**：仅使用 `lunar-python` 自带的星座判定 + 预置的行星位置静态表，适合 MVP 快速验证。

**输出**：
- 太阳星座、月亮星座、上升星座
- 行星在当前十二宫的分布
- 主要相位（V1.0 可选）

### 4.4 融合解读引擎

这是本项目的核心竞争力。核心思路：

```
输入: 用户八字 + 今日干支 + 今日黄历 + 用户星盘 + 今日星象
        ↓
     [规则引擎] 基础分析
        ↓
   ┌────┴────┐
   │ 五行生克 │ ← 日主 vs 今日干支的生克关系
   │ 十神互动 │ ← 今日对命局的十神影响
   │ 星座运势 │ ← 太阳/上升星座的今日星象
   │ 生肖冲合 │ ← 生肖与今日冲煞的关系
   └────┬────┘
        ↓
     [融合模块] 交叉解读
        ↓
   - 五行 × 星座元素(火象/土象/风象/水象) 交叉分析
   - 十神 × 行星 对应关系（如正官≈土星、正印≈木星等）
   - 黄历宜忌 × 星象建议 一致性/冲突检测
        ↓
     [LLM 增强] 自然语言润色 (optional)
        ↓
   输出: 自然语言运势解读
```

**中西对应关系（核心融合逻辑）**：

| 五行 | 星座元素 | 行星 |
|------|---------|------|
| 木 | 风象 (双子/天秤/水瓶) | 木星 |
| 火 | 火象 (白羊/狮子/射手) | 火星 |
| 土 | 土象 (金牛/处女/摩羯) | 土星 |
| 金 | — | 金星 |
| 水 | 水象 (巨蟹/天蝎/双鱼) | 水星/月亮 |

| 十神 | 行星对应 | 含义 |
|------|---------|------|
| 正官 | 土星 | 规则、责任、约束 |
| 偏官(七杀) | 冥王星 | 压力、变革 |
| 正印 | 木星 | 贵人、知识、扩张 |
| 偏印(枭神) | 天王星 | 灵感、突变 |
| 正财 | 金星 | 稳定财富 |
| 偏财 | 金星(逆行) | 意外之财 |
| 食神 | 月亮 | 享受、创造力 |
| 伤官 | 水星 | 才华、表达 |
| 比肩 | 太阳 | 自我、同伴 |
| 劫财 | 火星 | 竞争、冲动 |

## 五、技术方案

### 5.1 技术栈

| 层级 | 技术选型 | 理由 |
|------|---------|------|
| **前端框架** | React 18 + TypeScript | 生态成熟、组件化、支持 SVG/Canvas |
| **CSS 方案** | Tailwind CSS 3 | 快速开发、响应式、暗色模式 |
| **状态管理** | Zustand | 轻量、适合中等复杂度 |
| **图表/可视化** | D3.js / ECharts | 星盘图、八字排盘 |
| **后端框架** | Python FastAPI | 异步高性能、自动 OpenAPI 文档 |
| **数据库** | PostgreSQL 15 | 关系型，支持 JSON，地理坐标 |
| **缓存** | Redis | 会话管理、今日运势缓存 |
| **ORM** | SQLAlchemy 2.0 | Python 标准 ORM |
| **任务队列** | Celery + Redis | 异步计算（排盘可能耗时） |
| **八字引擎** | lunar-python (6tail) | 开源、功能完整、已验证 |
| **星盘引擎** | pyswisseph / flatlib | Swiss Ephemeris 精度 |
| **LLM 增强** | OpenAI API (GPT-4o) | 自然语言润色解读 |
| **部署** | Docker + Nginx | 容器化部署 |

## 九、风险与应对

| 风险 | 等级 | 应对策略 |

| 模式 | 说明 |
|------|------|
| **免费增值** | 每日运势免费，深度报告付费 |
| **VIP 订阅** | 月度/年度，解锁高级分析（流月、流年、合盘等） |
| **运势商城** | 虚拟商品：开运物品推荐、定制化报告 |
| **广告** | 非侵入式广告（谨慎使用） |

### 10.2 增长策略

- 分享卡片自带品牌水印 → 社交裂变
- 每日推送提醒 → 提升留存
- 节日/节气特殊运势 → 事件营销
- 与命理 KOL 合作 → 流量导入

### pyswisseph 测试结果

- 安装需要编译 C 扩展，在 macOS 上 pip install 约需 30 秒（可能因网络波动超时）
- 备选方案 flatlib（纯 Python）或使用 Docker 预编译镜像
- 或 MVP 阶段仅用 lunar-python 的星座判定，星盘深度分析延后到 Phase 2
